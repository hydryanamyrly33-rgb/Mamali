نصب ماملی روی Android و Windows

Mamali Orbit 3.0Android · Windows · بروزرسانی زنده

نصب روی Android

  1. سایت را با Google Chrome باز کنید.
  2. دکمه «نصب اپ اندروید» را بزنید؛ اگر نمایش داده نشد، منوی سه‌نقطه Chrome را باز کنید.
  3. گزینه Install app یا Add to Home screen را انتخاب و نصب را تأیید کنید.
  4. اپ با آیکون اختصاصی M در Launcher قرار می‌گیرد و مستقل از مرورگر اجرا می‌شود.

نصب روی Windows 10/11

  1. سایت را با Microsoft Edge یا Google Chrome باز کنید.
  2. آیکون Install در انتهای نوار آدرس یا گزینه Apps → Install Mamali را انتخاب کنید.
  3. پس از نصب، Mamali از Start Menu در پنجره مستقل اجرا و به Taskbar قابل Pin است.
  4. همان بروزرسانی زنده و حالت آفلاین Android روی نسخه Windows نیز فعال است.

چه چیزی آن را قابل نصب کرده؟

Web App Manifest
نام، رنگ، مسیر اجرا، حالت Standalone و آیکون‌های ۱۹۲ و ۵۱۲ پیکسلی
Service Worker
دریافت آنلاین تازه‌ترین نسخه و استفاده از کش فقط هنگام قطع اینترنت
HTTPS
میزبانی امن GitHub Pages؛ شرط اجرای Service Worker و نصب مطمئن
Responsive UI
رابط تطبیقی برای نمایشگر، لمس، صفحه‌کلید و حالت اپ
نسخه Windows و Android چطور کار می‌کند؟

هر دو نسخه از PWA استاندارد استفاده می‌کنند: روی Windows مثل یک برنامه مستقل در Start Menu و روی Android در Launcher نصب می‌شود. حذف و نصب دوباره لازم نیست؛ Update Center نسخه جدید را شناسایی و Service Worker آن را جایگزین می‌کند.
