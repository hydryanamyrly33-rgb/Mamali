نصب ماملی ۳.۳ — عمودی و امن

Mamali Orbit 3.3.0 · Secure PortraitAndroid · Windows · ورود گوگل در اپ + ضد اسکرین

نصب روی Android با قفل عمودی و ورود گوگل تعمیرشده

  1. سایت را با Google Chrome باز کنید. صفحه به صورت خودکار عمودی قفل می‌شود.
  2. با گوگل وارد شوید: اگر دکمه اصلی کار نکرد، از «باز کردن در مرورگر» یا «ریدایرکت امن» استفاده کنید.
  3. پس از ورود، مجوزهای نوتیفیکیشن و storage به صورت خودکار درخواست می‌شود — تایید کنید.
  4. دکمه «نصب اپ اندروید» را بزنید؛ اگر نمایش داده نشد، منوی سه‌نقطه Chrome → Install app.
  5. اپ با آیکون M در Launcher قرار می‌گیرد و همیشه عمودی و محافظت‌شده اجرا خواهد شد.

نصب روی Windows 10/11 — امن

  1. سایت را با Microsoft Edge یا Google Chrome باز کنید.
  2. آیکون Install در انتهای نوار آدرس یا گزینه Apps → Install Mamali را انتخاب کنید.
  3. پس از نصب، Mamali از Start Menu در پنجره مستقل اجرا و به Taskbar قابل Pin است.
  4. محافظت از اسکرین‌شات با overlay و بلوکه PrintScreen در ویندوز هم فعال است.

برای ساخت APK واقعی با FLAG_SECURE:

اگر از PWABuilder یا WebIntoApp استفاده می‌کنید، در MainActivity.java بعد از super.onCreate() اضافه کنید:
getWindow().setFlags(WindowManager.LayoutParams.FLAG_SECURE, WindowManager.LayoutParams.FLAG_SECURE);
و در AndroidManifest.xml برای اکتیویتی اصلی: android:screenOrientation="portrait" و android:configChanges="orientation|screenSize"
